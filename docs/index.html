How to build agents that actually work

Slide-style lessons on building AI agents that run on your own computers, drawn from Stanford CS329Z (Engineering AI Agents) and CS329A (Self-Improving AI Agents). Each lesson links to the original lecture slides and a runnable Colab notebook.

The one idea to remember: a great agent is mostly not the model. It is an eval you trust, a simple workflow, a few good tools, a clean context, hard rules in code, and a loop that turns every mistake into a test. The weaker the model, the more this matters, which is why it is the core of what Local AI Lab sells.
Run every module in Google Colab.

Each module has an Open in Colab button. The notebook installs a free open model (Meta Llama 3.1 8B via Ollama) on Colab's free T4 GPU and runs everything locally: no API keys, no data leaving the machine. In Colab, pick Runtime → Change runtime type → T4 GPU, then run the first cell (2–3 minutes).

All notebooks and the two projects: github.com/shivamkalakaar/local-ai-lab-agents

How to use this course
  1. Pick a card below. Each lesson is a short set of slides: one idea per slide, short bullets, side-by-side examples.
  2. Answer the three questions at the end of the lesson to check you got it.
  3. Open the module in Colab and run the code. It runs a free open model on Colab's GPU, with no API keys.
  4. Want more detail? Each page has a "Go deeper" section with key terms, papers and the full code.
